Bulk CSV Formatting Guide

Important: Please do not modify, rename, or delete the first row (Header Row) of the provided CSV file. Modifying the headers will cause the upload to fail.

Image Upload Protocol

Because high-quality images make the file size too large for a CSV, Muziris uses a separate secure folder for your media.

  1. Open the secure Google Drive link sent in your automated email.
  2. Upload all your product photos (JPEG, PNG) directly into that folder.
  3. In the CSV file, under the image columns (e.g., Hero Img), simply type the exact file name (e.g., bottle-front.jpg).
  4. Our data team will automatically sync the images from the folder to the data on your CSV.

Column Definitions

Column Name Instructions
DateToday's date (YYYY-MM-DD).
Supplier IDYour official Muziris ID. This MUST be included on every single row.
CompanyYour registered company name.
Main Category & Sub CategoryThe classification of the item.
Var Type & Var OptionIf the product has variations (e.g., Var Type: "Color", Var Option: "Red"). For single products, write "Standard".
Min Qty & Max QtyThe minimum and maximum order quantity for this specific price tier.
PriceThe numerical price. Do not include currency symbols (e.g., write "12.50", not "$12.50").
Product ID & Variant IDLEAVE THESE BLANK. The Muziris ledger will auto-generate unique secure hashes for these when processing.
Lead TimeEstimated production time in days (e.g., "30").
